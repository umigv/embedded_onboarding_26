## 2. Software Installations

### VS Code
1. Download and install [VS Code](https://code.visualstudio.com/download).
2. Open VS Code and go to the **Extensions** tab on the left navigation bar.
3. Search for and install:
   - **C/C++** (by Microsoft)
   - **C/C++ Extension Pack**
   - **C/C++ Themes**

### Arduino IDE
Download and install [Arduino IDE 2.x](https://www.arduino.cc/en/software). This is used to compile and upload code to microcontrollers such as Arduino Uno and Mega.

### STM32CubeIDE
Download and install [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html) to program STM32 microcontrollers. 
> **Mac Users:** Also install [ST-LINK Server](https://www.st.com/en/development-tools/st-link-server.html).

### Git
- **Windows:** Download and install [Git for Windows](https://git-scm.com/downloads). Optionally, install [GitHub Desktop](https://desktop.github.com/) for a GUI experience.
- **macOS / Linux:** Install Git via Homebrew (`brew install git`) or system package manager.

### GitHub Account
1. Sign up for a [GitHub](https://github.com/) account using your `umich.edu` email.
2. Link your local machine to GitHub following the [GitHub Quickstart Guide](https://docs.github.com/en/get-started/quickstart/set-up-git).
3. Review the [Git Intro Guide](https://github.com/umigv/embedded_onboarding/blob/main/git_intro.md) to familiarize yourself with git workflows.

### Anaconda
Recommended terminal environment for Python development on Windows (optional on macOS). Download from [Anaconda Downloads](https://www.anaconda.com/download).
