## 1. Onboarding Development Steps

1. **Analyze Existing Documentation & Projects:**
   - Skills taught: Problem solving, hardware ideation, system planning.
   - Core sub-domains: Arduino, ROS 2, Altium PCB Design, ODrive, Kraken, LiDAR FPGA acceleration.
2. **Review System Requirements:**
   - Software: Ubuntu 22.04 LTS (ROS 2 Humble), Docker Desktop, VS Code, Altium Designer, Intel Quartus Lite.
   - Hardware: Arduino kits, USB cables/adapters, ODrive S1/v3.6 controllers, DE10-Nano FPGA boards.
3. **Conduct Lead & Feedback Reviews:**
   - Gather input from previous team leads and onboarding members to eliminate friction.
4. **Track-Based Learning Paths:**
   - **Embedded/Robotics Track:** Arduino -> ODrive -> ROS 2
   - **PCB/Hardware Track:** Arduino -> Altium / KiCad -> Custom Shield Design
   - **Computer Architecture Track:** Verilog FSMs -> DE10-Nano FPGA / Quartus -> LiDAR ISP
